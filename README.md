**Hardware & automation**

**Desktop & CLI tools**
- [sitright](https://github.com/A2M33/sitright): webcam posture, blink and break reminders
- [clickforge](https://github.com/A2M33/clickforge): rebindable auto clicker with a Stream Deck plugin
