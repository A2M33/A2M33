I'm Amin, from Tehran, preparing for an Ausbildung in Germany as a Fachinformatiker or in industrial automation. I like projects where code touches the physical world, like a webcam that notices you slouching or an ESP32 display on my desk.

I build small tools people can use and commit as I go, so each repo's history shows how it came together.

### Projects

- **[sitright](https://github.com/A2M33/sitright)**: tray app that watches your posture through the webcam and reminds you to sit up, blink and take breaks, all offline. <sub>`Python` `MediaPipe` `OpenCV`</sub>
- **[deskpal](https://github.com/A2M33/deskpal)**: ESP32 desk display with clock, weather, room climate and my GitHub contribution grid on a 128x64 OLED. <sub>`C++` `Arduino` `ESP32`</sub>
- **[artikel](https://github.com/A2M33/artikel)** · [try it](https://a2m33.github.io/artikel/): practise der, die and das with 900+ German nouns, spaced repetition and English/Persian meanings. <sub>`HTML` `CSS` `JavaScript`</sub>
- **[practicemeter](https://github.com/A2M33/practicemeter)** · [try it](https://a2m33.github.io/practicemeter/): practice timer for musicians that counts only the minutes you play, using the browser microphone. <sub>`JavaScript` `Web Audio`</sub>
- **[clickforge](https://github.com/A2M33/clickforge)**: Windows tool that turns one mouse click into many, with a rebindable toggle, a keyboard-LED status light and a Stream Deck plugin. <sub>`Python` `Win32` `Node.js`</sub>
- **[spacetrail](https://github.com/A2M33/spacetrail)**: daily folder-size snapshots that show which folders ate your disk space this week. <sub>`Python` `SQLite`</sub>
- **[histpick](https://github.com/A2M33/histpick)**: pick commands from your shell history and save them as a script for PowerShell, bash, zsh or fish. <sub>`Python`</sub>
